About This App

Personal Forex Signal Engine — a private, free-tier tool for multi-timeframe confluence-based analysis.

Architecture

  • Backend: GitHub repository (JSON files as database)
  • Automation: GitHub Actions runs every 15 minutes — fetches data, validates, runs engine, commits signals
  • Signal engine: Pure JavaScript in engine/ — identical code runs in browser, Actions, backtester, and tests
  • Frontend: Vanilla JS + Lightweight Charts (TradingView) hosted on GitHub Pages
  • Market data: Twelve Data (primary) with Yahoo fallback; provider provenance is always recorded

Signal Hierarchy (D1 → H4 → H1 → M15 → M5)

Higher timeframes establish context (trend, key levels). Lower timeframes confirm entries and refine timing. Signals are only emitted when multiple factors align across the hierarchy.

Signal Strength vs. Reality

"Strength" is a confluence score (0–100) measuring rule alignment — it is not a probability of winning. Win-rate statistics must come from forward testing and backtesting, never from the strength score alone.

Immutability

Once a signal is generated, it is never overwritten. Every signal records strategy version, timestamp, provider, data quality, and reasoning so that historical performance can be audited honestly.
